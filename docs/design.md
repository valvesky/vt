# What is a Terminal Emulator?

A terminal is emulator is a graphical application responsible for opening a shell,
such as `bash`, feeding it the user's input and properly displaying it's output on the 
screen.

A shell is what is actually interfacing with your operating system, our responsibility
is only to spawn it, give it some information, feed it input, parse it's output correctly
and display it on the screen.
