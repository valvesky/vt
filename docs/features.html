Drag and drop

Two features. ctl: docs/ctl.md.

Intra-window panes

Middle-drag a live pane of mine. Edge drop splits dest, center swaps. Same process. Any Peak that delivers MMB. Shift+MMB stays paste.

vt → vt pane handoff

Middle-release moves a live PTY into dest vt as a new pane. My single-pane donor dies. I use ctl + SCM_RIGHTS, not OS window DnD.

One-shot (release on dest)Two-click (MMB source, then dest)
