Name

vt - a lovable terminal emulator

Synopsis

git clone http://github.com/valvesky/vt --recursive
cd vt
gcc build.c -o build
sudo ./build install

Description

VT is a lovable terminal emulator. It's cross-platform, fast, has most of the features you will ever need, and can be easily extended to fit your needs.

You can either:

  1. Clone the source code and create your own custom fork to your liking (recommended, see the synopsis above);
  2. Or use a packaged version and configure it via ~/.config/vt/config.toml.

By default, it will be compiled with a GPU backend (Vulkan 1.4). You can compile with a CPU or with a CPU rasterizer via ./build cpu. More backends will be built into Rend in the future.

Hacking

The repo comes with several pre-built "patches" with features that specific users may want to apply to extend VT's capabilities:

  • Sixel support (VT comes with Kitty image support)
  • undercurl
  • various color themes (NOTE: colors will be overwritten by the .toml file)
  • etc.

You can basically just ask an agent to apply whatever patches you want for you. An AGENTS.md file exists alongside agent-targeted documentation in docs/agents so that this process is smooth and spends minimal tokens.

You can also do it yourself via: 

patch -p1 < patches/patch.diff

CONFIG

Compile-time settings can be found in config.h. Runtime settings will be applied in the TOML config and override the previous settings.

SIGUSR0 will cause VT to reload its settings!

Design

VT's design is directly influenced by Casey Muratori's refterm. You could even call it an implementation of sorts, although none of the original code was used. The architecture, however, aims to be identical.

We start by routing stdin and stdout via a pipe; then we feed that pipe to a mirrored circular buffer until EOF.

Preparsing is done to separate easy and hard-to-parse data. This preparsing is accelerated via SIMD intrinsics.

Implementation Details

VT is built on top of a minimal set of C99 libraries that I maintained, called the godstack. All of these are directly included in the source code and statically linked.

Peak - Platform Layer - Includes platform-specific code at compile time and automagically links OS headers at runtime.

Rend - Rendering Layer - Thin-ish Vulkan wrapper that also supports CPU rasterization.

Term - VT Parsing - Stores the actual screen and associated glyphs. Demands specific input.
